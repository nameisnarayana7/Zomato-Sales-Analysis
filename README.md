## 📌 Project Overview

The **Zomato Data Analysis** project focuses on performing Exploratory Data Analysis (EDA) on restaurant data to discover meaningful insights into restaurant trends, customer preferences, pricing strategies, and customer ratings.

Using Python and data visualization libraries, this project transforms raw restaurant data into meaningful information that can help understand the food industry and customer behavior.

### 🎯 Project Objectives

- Understand restaurant distribution across different locations.
- Identify popular cuisines and restaurant categories.
- Analyze restaurant ratings and customer satisfaction.
- Explore the relationship between cost and ratings.
- Evaluate online delivery and table booking trends.
- Discover patterns that influence restaurant performance.

---

## 📊 Dataset Information

**Dataset:** Zomato Restaurant Dataset

The dataset contains restaurant-related information, including:

| Column | Description |
|---|---|
| Restaurant Name | Name of the restaurant |
| Location | Restaurant location |
| Cuisines | Types of cuisines served |
| Ratings | Customer ratings |
| Cost for Two | Approximate dining cost for two people |
| Online Delivery | Online ordering availability |
| Table Booking | Table reservation availability |

## ⚙️ Installation & Execution

### Step 1: Clone Repository

```bash
git clone https://github.com/nameisnarayana7/Zomato-Data-Analysis.git
```

### Step 2: Navigate to Project

```bash
cd Zomato-Data-Analysis
```

### Step 3: Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Alternatively:

```bash
pip install -r requirements.txt
```

### Step 4: Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the Zomato EDA notebook and execute the cells to explore the analysis.
